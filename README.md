# Skills

Koda 从 GitHub 学到的技能库，每周更新。每个技能一个目录，含 SKILL.md（用法）和 skill.yaml（元数据）。

| 技能 | 说明 |
| --- | --- |
| lip-sync-dubbing | Give generated video clips matching dialogue with lip sync and AI voices, using ElevenLabs, Fish Audio, GPT-SoVITS, MuseTalk, LatentSync, or hosted lip sync services. |
| security-audit-skill | Run a multi-phase security audit on a codebase with a coding agent: reconnaissance, coverage-led hunting, candidate validation, structured findings, independent verification, and reporting. |
| ruflo | Run Ruflo, the agent meta-harness for Claude Code and Codex: swarms, self-learning memory, federation, and the agent console. |
| knowledge-work-plugins | Install and use Anthropic's open-source Claude plugins for knowledge work: sales, support, product, marketing, legal, finance, data, enterprise search, and more. |
| opencode | Install and use OpenCode, the open-source terminal AI coding agent with build and plan agents, plus its desktop app. |
| orca | Run Orca, the desktop orchestrator for a fleet of CLI coding agents: parallel git worktrees, mobile companion, terminal splits, and design mode. |
| hyperframes | Make MP4 videos from HTML, CSS, and seekable animations with HyperFrames: CLI projects, agent skills, registry components, and rendering. |
| android-skills | Use Google's official Android skills to help coding agents follow Android best practices: install via Android CLI or as an agent plugin, then prompt by task. |
| graphify | Map any codebase into a queryable knowledge graph with Graphify: local tree-sitter AST parsing, explain/path/query commands, and an agent skill. |
| ai-memory | Give coding agents long-term, cross-agent memory with ai-memory: zero-LLM capture, git-backed markdown wiki, and claim-once handoffs between agents. |
| comfyui | Generate images, video, audio, and 3D locally with ComfyUI's node graph: desktop app or comfy-cli install, workflow basics, model placement, and shortcuts. |
| voicestudio | Run VoiceStudio, the open-source fully-local ElevenLabs alternative: voice cloning, voice design, video dubbing, dictation, transcription, and audiobook creation in 646 languages. |
| claude-plugins-official | 查官方 Claude Code 插件目录并按需安装：内部插件与审核过的第三方插件的市场结构、安装命令与信任注意事项。 |
| vllm | 用 vLLM 在 GPU 上高吞吐跑大模型：PagedAttention、连续批处理、OpenAI 兼容服务与量化、并行等核心用法。 |
| andrej-karpathy-skills | 用 Karpathy 四原则约束编码 Agent：先想再写、简单优先、精准改动、目标驱动，减少猜测、臃肿与无关改动。 |
| t3code | 用手机、网页或桌面 App 控制本机编码 Agent：多 Agent 会话管理、远程访问与后台服务用法。 |

| impeccable | 用 24 个动词命令指挥 Agent 改设计，用 critique/audit 评审已有界面，用 62 条确定性规则的检测器在上线前抓 AI 味。 |
| superpowers | 用 Superpowers 的强制工作流做开发：先问需求、再写设计、拆成小任务、红绿 TDD、子 Agent 执行并逐项评审。 |
| claude-seo | 用 Claude SEO 给网站做完整审计：技术 SEO、内容 E-E-A-T、Schema、AI 搜索引用与 Agent 就绪度，10–15 分钟出按优先级排序的行动计划。 |
| agent-browser | Drive a real browser from the shell for AI agents: open pages, read them as an accessibility tree, and click, fill, screenshot, and verify step by step with agent-browser. |
| spec-kit | Build with a spec first using GitHub Spec Kit: constitution, specify, plan, tasks, implement, converge, plus bug-fixing and idea-assessment processes for AI coding agents. |
| scrapling | Scrape public web data lawfully with Scrapling: fast HTTP and browser fetching, CSS/XPath parsing, concurrent spiders with pause/resume, Markdown export, and a CLI — with robots.txt, rate limits, and terms-of-service compliance built into the workflow. |
| humanizer | Remove signs of AI-generated writing from text: 26 patterns from Wikipedia's Signs of AI writing, rewritten to sound human without changing the meaning. |
| explain_interface | Explain how a website, a visual effect or an animation was built, from a live URL or a screenshot: layer stacks in paint order, measured vs derived vs inferred claims, and a transferable recipe. |
